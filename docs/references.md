# References and attribution

- [macsima2mc](https://github.com/SchapiroLabor/macsima2mc): MACSima acquisition staging for MCMICRO, including orientation guidance and upstream licensing.
- [ASHLAR](https://github.com/labsyspharm/ashlar): tile stitching and cycle registration implementation. Use its linked paper and citation guidance when reporting results.
- [MCMICRO](https://mcmicro.org/): modular image-processing pipeline. [Parameters](https://mcmicro.org/parameters/) describe stage selection and registration options.
- [tifffile](https://github.com/cgohlke/tifffile): TIFF and OME-TIFF reading/writing.
- [scikit-image registration](https://scikit-image.org/docs/stable/api/skimage.registration.html): phase cross-correlation used for exploratory QC measurements.

This repository's wrappers and QC do not replace upstream attribution. Package licenses and installed source copies retain their original terms. No new license is assigned to upstream code by this repository.
